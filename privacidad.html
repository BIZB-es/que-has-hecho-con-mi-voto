Responsable del tratamiento

El responsable de los datos personales que se traten directamente con motivo de las consultas y comunicaciones relacionadas con este portal es Trust Society BISB, S.L. (BIZB), NIF B01964618.

Contacto: qhhcmv@bizb.es. Dirección postal de contacto: Calle Bailén, 2, 28231 Las Rozas de Madrid (Madrid), España.

Qué información se trata

Al visitar la web: el portal se publica como sitio estático. El código de esta versión no incluye analítica comercial, publicidad comportamental, alta de usuarios ni formularios que envíen automáticamente sus datos a BIZB. GitHub Pages, como servicio de alojamiento, puede registrar direcciones IP y datos técnicos por motivos de seguridad.

Si escribes al correo de contacto: podremos tratar tu nombre (si lo facilitas), correo electrónico, el contenido del mensaje, sus archivos adjuntos y la información necesaria para responder y gestionar una rectificación.

Datos parlamentarios publicados: se muestran nombres, cargos, intervenciones y votos referidos al ejercicio de funciones públicas, obtenidos de fuentes oficiales u otras fuentes documentadas. Pueden solicitarse correcciones por el canal habilitado.

Finalidades y bases jurídicas

Los mensajes recibidos se utilizan para responder consultas, revisar incidencias y documentar correcciones. La base jurídica dependerá del caso: el interés legítimo en mantener un canal de contacto y un observatorio verificable, o el cumplimiento de una obligación legal cuando se ejerciten derechos regulados.

La información pública sobre actividad parlamentaria se presenta con finalidad informativa y de transparencia, ponderando la relevancia pública de la información y los derechos de las personas afectadas. No se utiliza para elaborar perfiles de los visitantes.

Alojamiento, proveedores y enlaces externos

El sitio está preparado para alojarse en GitHub Pages, que puede registrar la dirección IP de las visitas para seguridad del servicio. El tratamiento del proveedor queda explicado en su declaración de privacidad.

El servicio de correo utilizado para recibir mensajes puede tratar los datos necesarios para su prestación. Al seguir enlaces a instituciones, portales de datos u otras webs externas, se aplicarán las políticas de sus respectivos titulares.

La utilización de proveedores internacionales puede conllevar transferencias internacionales sujetas a las garantías que correspondan al servicio concreto. No se venden datos de los usuarios ni se emplean para publicidad comportamental desde este portal.

Preferencias locales y cookies

El código revisado para esta versión no configura cookies propias de publicidad ni de medición de audiencias. La sección parlamentaria guarda en el almacenamiento local del navegador una preferencia de visualización (qhv-mode: modo sencillo o avanzado). Esa preferencia no identifica por sí misma a la persona y puede borrarse desde las opciones del navegador.

Si en futuras versiones incorporamos medición de audiencia, formularios o servicios que requieran consentimiento, actualizaremos la información y, cuando corresponda, solicitaremos autorización antes de activarlos.

Conservación y derechos

Los mensajes se conservarán durante el tiempo necesario para atender la consulta o petición y, cuando proceda, durante los plazos exigidos para documentar incidencias y obligaciones legales. Evita remitir información personal innecesaria.

Puedes solicitar acceso, rectificación, supresión, oposición, limitación o portabilidad de tus datos, cuando proceda, escribiendo a qhhcmv@bizb.es. Las solicitudes de ejercicio de derechos se atenderán conforme a los plazos y requisitos legales. Si consideras vulnerados tus derechos, puedes dirigirte a la Agencia Española de Protección de Datos (AEPD).
